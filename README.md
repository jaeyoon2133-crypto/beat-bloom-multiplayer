# BEAT BLOOM PeerServer

Render settings (Root Directory `server`):
- Build: `npm install`
- Start: `npm start`
- Health check: `/health`

Optional iPhone/mobile TURN relay: configure `METERED_TURN_DOMAIN` and `METERED_TURN_API_KEY` in Render Environment. See the repository root `README.md` for the setup steps. Keep the API key in Render; do not commit it to GitHub.
